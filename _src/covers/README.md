# Covers, mockup and pin (lote 7a)

Drawn in code by `_src/update_041_covers.py` with the site's own fonts (Fraunces and Inter, SIL Open Font License) and colors. No photos and no AI.

## Files

| File | Use |
|---|---|
| `nourished-main-guide-cover.png` / `.pdf` | New page 1 for the main guide PDF |
| `bonus-1-28-day-meal-plan-cover.png` / `.pdf` | New page 1 for the 28-Day Meal Plan |
| `bonus-2-recipe-pack-vol-2-cover.png` / `.pdf` | New page 1 for Recipe Pack Vol. 2 |
| `bonus-3-printable-pack-cover.png` / `.pdf` | New page 1 for the Printable Pack |
| `starter-kit-cover.png` / `.pdf` | New page 1 for the free Starter Kit |
| `nourished-bundle-mockup.png` (transparent) / `.jpg` | The four PDFs together, for the sales page, pins and posts |
| `pin-nourished-bundle.jpg` | Pinterest pin, 1000x1500 |

The `.pdf` covers are US Letter (8.5 x 11 in) and can replace page 1 of each PDF.

## Order of use

1. Review the covers.
2. Replace page 1 of each PDF with the matching cover (together with the other PDF corrections).
3. Only then does the sales page start using the mockup and the new covers, so the site never shows a cover that differs from the files buyers receive.

Each cover describes only what that file contains. The bundle-level numbers (36 recipes, four weeks of examples) appear only on the mockup pin, which shows all four files.

To change the design, edit `update_041_covers.py` and bump `DESIGN_VERSION`; the next build redraws everything.
