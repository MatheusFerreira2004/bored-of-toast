# Bored of Toast

Recipe content site. Publishes recipes and cooking tips (do's and don'ts), driven by traffic from Pinterest and Facebook. Monetization: non-predatory advertising + a digital product (not yet defined).

## Status

Early scaffold. Planning brief lives in ChatPRD ("Bored of Toast — Recipe Site Landing Page Brief").

Open decisions (not yet finalized):
- Primary conversion goal for the homepage (browse recipes vs. email capture vs. product purchase)
- Digital product definition (what it is, pricing, name)
- Final visual design direction (current styling uses placeholder colors approximated from the logo; confirm exact brand hex values)

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Deployment target: Vercel (connect this repo in the Vercel dashboard for automatic deploys on push)

## Local development

```bash
npm install
npm run dev
```

Then open http://localhost:3000
